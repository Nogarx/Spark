spark.core.tracers.contract_tracer_args(axes, shape, **values)[source]#

Reduces the arguments of a tracer over the axes its output is summed on.

A tracer whose arguments are constant along the summed axes gives the same result when it is applied to the summed value instead of to each entry, which holds far less state.

Parameters:

  • axes (tuple of int) – Axes the trace is summed over.

  • shape (tuple of int) – Shape of the trace before the sum.

  • **values (Any) – Arguments of the tracer.

Returns:

  • reduced (dict of str to Any) – The arguments, contracted when possible.

  • contracted (bool) – True when every argument was contracted, so the caller may build the smaller tracer.

Return type:

tuple[dict[str, Any], bool]

Base class for exponential traces.

A tracer holds a value that decays towards a base between calls and is driven by whatever is passed in. Subclasses provide _update, which advances the trace one step.

  • shape (tuple of int) – Shape of the trace.

  • dt (float, default 1.0) – Integration step, in ms.

  • dtype (DTypeLike, optional) – Dtype of the trace.

class spark.core.tracers.RDTracer(shape, tau_rise, tau_decay, scale_rise=1, scale_decay=1, base_rise=0, base_decay=0, **kwargs)[source]#

Bases: BaseTracer

Rise-and-decay trace.

The difference of two single exponentials, which rises over tau_rise and falls over tau_decay instead of jumping on the step a value arrives.

Parameters:

  • shape (tuple of int) – Shape of the trace.

  • tau_rise (jax.Array or float) – Rise constant, in ms.

  • tau_decay (jax.Array or float) – Decay constant, in ms.

  • scale_rise (jax.Array or float, default 1) – Factors applied to the incoming value in each component.

  • scale_decay (jax.Array or float, default 1) – Factors applied to the incoming value in each component.

  • base_rise (jax.Array or float, default 0) – Values each component decays towards.

  • base_decay (jax.Array or float, default 0) – Values each component decays towards.

Notes

The rise constant is coupled to the decay constant as

\[\tau_r' = \frac{\tau_r \tau_d}{\tau_r + \tau_d}\]

which keeps the peak at the intended height as the two constants approach each other. The trace is the decay component minus the rise component.

class spark.core.tracers.RFSTracer(shape, alpha, tau_rise, tau_fast_decay, tau_slow_decay, scale_rise=1, scale_fast_decay=1, scale_slow_decay=1, base_rise=0, base_fast_decay=0, base_slow_decay=0, **kwargs)[source]#

Bases: BaseTracer

Rise, fast decay and slow decay trace.

A blend of two RDTracer traces that share a rise constant and differ in their decay constants, so one input leaves both a fast transient and a slow tail.

Parameters:

  • shape (tuple of int) – Shape of the trace.

  • alpha (jax.Array or float) – Weight of the fast component. The slow component takes 1 - alpha.

  • tau_rise (jax.Array or float) – Rise constant shared by both components, in ms.

  • tau_fast_decay (jax.Array or float) – Decay constants of the two components, in ms.

  • tau_slow_decay (jax.Array or float) – Decay constants of the two components, in ms.

  • scale_rise (jax.Array or float, default 1) – Factors applied to the incoming value.

  • scale_fast_decay (jax.Array or float, default 1) – Factors applied to the incoming value.

  • scale_slow_decay (jax.Array or float, default 1) – Factors applied to the incoming value.

  • base_rise (jax.Array or float, default 0) – Values each component decays towards.

  • base_fast_decay (jax.Array or float, default 0) – Values each component decays towards.

  • base_slow_decay (jax.Array or float, default 0) – Values each component decays towards.

Notes

\[T = \alpha T_{\mathrm{fast}} + (1 - \alpha) T_{\mathrm{slow}}\]
