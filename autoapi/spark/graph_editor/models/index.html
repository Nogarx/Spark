set_profile(profile, force=False)[source]#

Sets the controller profile of the graph.

The profile determines which modules may be placed and how the graph is exported. It can only change while the graph is empty, except when loading a model, where the file dictates it.

Parameters:

  • profile (ControllerProfile or None) – The new profile.

  • force (bool, default False) – Apply the profile regardless of the current content. Reserved for loading.

Returns:

True if the profile was applied.

Return type:

bool
