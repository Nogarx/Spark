spark.recording.current.open_recorder()[source]#

Returns the open recorder of the calling thread, or None when no recorder is open.

Raises:

RuntimeError – When the thread opened no recorder, and several are open in other threads.

Return type:

spark.recording.recorder.Recorder | None

spark.recording.current.log(values=None, *, step=None, tag=None, **scalars)[source]#

Writes scalars held on the host to the open recorder, as Recorder.log.

Does nothing when no recorder is open.

Parameters:

  • values (dict of str to float, optional) – Scalars by name.

  • step (int, optional) – Step of the scalars. The current step by default.

  • tag (str, optional) – Name of the integer tag the scalars are logged per. Per step without one.

  • **scalars (float) – Scalars by name, added to values.

Raises:

RuntimeError – When the thread opened no recorder, and several are open in other threads.

Return type:

None

Examples

>>> spark.recording.log({'episode/steps': 212}, tag='episode')
spark.recording.current.event(kind, *, step=None, **payload)[source]#

Writes an event to the open recorder, as Recorder.event.

Does nothing when no recorder is open.

Parameters:

  • kind (str) – Kind of the event.

  • step (int, optional) – Step of the event. The current step by default.

  • **payload – Payload of the event, written as JSON.

Raises:

RuntimeError – When the thread opened no recorder, and several are open in other threads.

Return type:

None

Examples

>>> spark.recording.event('episode_end', outcome='fell')

spark.recording.current.raw(name, frame, *, step=None)[source]#

Keeps a frame of a raw stream in the open recorder, as Recorder.raw.

Does nothing when no recorder is open.

Parameters:

  • name (str) – Name of the raw stream, as declared by Measurements.

  • frame (array-like) – Array of numbers or bools, such as an observation.

  • step (int, optional) – Step of the frame. The current step by default.

Raises:

RuntimeError – When the thread opened no recorder, and several are open in other threads.

Warns:

RecordingWarning – When the open recorder has no measurements declaring name, or the frame is invalid. The frame is dropped.

Return type:

None

Examples

>>> spark.recording.raw('env/observation', observation)
spark.recording.current.record(name, steps=1)[source]#

Records the measurements name for the next steps steps in the open recorder, as Recorder.record.

Does nothing when no recorder is open.

Parameters:

  • name (str) – Name of the measurements.

  • steps (int, default 1) – Steps to record them for.

Raises:

RuntimeError – When the thread opened no recorder, and several are open in other threads.

Warns:

RecordingWarning – When the open recorder has no measurements name. Nothing is recorded.

Return type:

None

Examples

>>> spark.recording.record('episode')
