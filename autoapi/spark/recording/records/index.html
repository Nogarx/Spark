spark.recording.records.split_key(name)[source]#

Splits the name of an array of a window file into its address, mode and part.

'<address>@<mode>#<part>' gives (address, mode, part), the part being 't' for the steps of rows, or the name of a reduction. 'raw:<name>#t' gives (name, 'raw', 't'). A name without a part gives a part of None, and the other names, such as 'span_t0', give (name, None, None).

class spark.recording.records.Record(key, t0, t, *, traces=None, rasters=None, raw=None, summaries=None, deltas=None, snapshots=None)[source]#

Object holding a collection of measurements recorded over one group of steps (Measurements.group).

The data is held by type, addressed by the type of the probe:

  • traces, rasters and raw (by stream name): Rows, the rows and their steps.

  • summaries and deltas: Reductions, the reductions of the group by name.

  • snapshots: the value at the end of the group, an array.

Parameters:

key[source]#

For a group by tag, the value of the tag: (value, n) the n-th time the value comes back, None for the steps before the tag is first set. For a group of n steps, its number g, of the steps [g * n, (g + 1) * n). Without a group, the first step of the stretch.

object
