spark.recording.utils.integer(value, name, lowest=None, highest=None, owner=None)[source]#

Returns value as an int, or raises a ValueError naming name.

value must be a whole number (whole), at least lowest and at most highest when they are given.

Parameters:

  • value (object) – Value to check.

  • name (str) – Name of the argument, for the error message.

  • lowest (int, optional) – Bounds of the value, both included.

  • highest (int, optional) – Bounds of the value, both included.

  • owner (str, optional) – What the argument belongs to, such as 'Every', leading the error message.

Return type:

int

Raises:

spark.recording.utils.hold_interrupt(armed=True)[source]#

Holds SIGINT while the block runs. A second SIGINT raises KeyboardInterrupt at once.

Without armed, a second SIGINT is held as well until HeldInterrupt.arm. The SIGINT held is not delivered when the block ends: HeldInterrupt.deliver delivers it.

Parameters:

armed (bool, default True) – Whether a second SIGINT raises from the start of the block.

Returns:

Yields the HeldInterrupt, or None away from the main thread and while SIGINT is ignored, where nothing is held.

Return type:

context manager
