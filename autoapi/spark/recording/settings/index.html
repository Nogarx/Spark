spark.recording.settings#

Settings of spark.recording: the thresholds, periods and timeouts the recorder works with.

SETTINGS holds the settings of the process. Each one is read when it is used, so a change applies from its next use.

Attributes#

SETTINGS

The settings of spark.recording in use.

Classes#

RecordingSettings

The thresholds, periods and timeouts of spark.recording.

Module Contents#

class spark.recording.settings.RecordingSettings[source]#

The thresholds, periods and timeouts of spark.recording.

SETTINGS holds the settings in use. Each one is read when it is used, so a change applies from its next use. Setting an attribute that is not a setting raises AttributeError.

A setting read while a function is traced, such as the limits of the reductions, applies to the calls traced after the change. Calls compiled before keep the value they were traced with.

Examples

>>> spark.recording.SETTINGS.open_timeout = 1200.0
variant_warning: int = 16[source]#

Number of distinct sets of recorded measurements past which Recorder.probes warns. Each set is compiled once.

tag_warning_calls: int = 100[source]#

Calls of the model after which Recorder.probes warns about triggers counting a tag never set as an integer, and about measurements grouped by a tag never set.

warmup_calls: int = 100000[source]#

Bound on the calls of the model Recorder.warmup_sets simulates.

warmup_subsets: int = 64[source]#

Number of probe sets past which Recorder.warmup_sets adds the measurements not recorded by a step trigger one at a time and all together, instead of in every combination.

requests_every: float = 0.5[source]#

Seconds between two reads of the requests of a run by the writer.

request_reads: int = 10[source]#

Attempts the writer makes at reading a request file before it rejects the request.

commit_every: float = 1.0[source]#

Seconds between two commits of the index while items keep arriving. Scalars, events, tags, spans and groups reach the index at most about this long after the writer handles them.

retry_after: tuple[float, ...] = (1.0, 4.0)[source]#

Seconds waited before each new attempt at a file write or an operation on the index that failed with a transient error, as network file systems give. A write that fails every attempt fails the writer.

open_timeout: float = 600.0[source]#

With several processes, seconds process 0 waits for every other process to create its recorder before it raises.

sync_timeout: float = 86400.0[source]#

With several processes, seconds a process waits for a decision of process 0, or for the other processes at a barrier, before it raises.

signals_every: float = 0.5[source]#

Seconds between two reads, by process 0, of the signals the other processes received.

decision_block: int = 1000[source]#

With several processes, calls of the model after which every process waits for the others at a barrier. No process runs more than a block ahead of another. The decisions of the block before the last are then removed from the key-value store of jax.distributed.

masked_slots: int = 4[source]#

Largest number of groups of a call for which a summary updates the statistics of every group on every step, masked to the group of the step. With more groups, only the statistics of the group of the step are read and written, at a dynamic index.

select_per_step: int = 4096[source]#

Smallest size of a value from which scattered units of a trace or raster, at most a quarter of its entries, are selected on every step. Below it, whole values are stacked and their units selected after the scan.

histogram_compare_limit: int = 2097152[source]#

Largest bins * values a histogram counts by comparing every value with every edge. Beyond it, with more than histogram_compare_bins bins, the bin of each value is computed and the values are counted by bin.

histogram_compare_bins: int = 8[source]#

Largest number of bins for which a histogram compares every value with every edge, for any number of values.

histogram_scatter_limit: int = 262144[source]#

Most values a histogram counts by scattering them into their bins, on backends other than the CPU. Beyond it, their bin indices are sorted and counted by a search, except on the CPU, which always scatters.

histogram_rows_limit: int = 16777216[source]#

Largest size in bytes of the values of all the steps of a call that a histogram stacks on the device and counts after the call. Beyond it, the histogram counts the values of each step within the step, with device memory in proportion to its bins.

spaced_rows_limit: int = 16777216[source]#

Largest size in bytes of the values of all the steps of a call that a trace or raster with a stride stacks on the device, the steps it does not keep included. Beyond it, only the steps kept are written, to a buffer of their own, with one write per step.

busy_timeout: float = 60.0[source]#

Seconds a statement of the recorder waits for readers holding the index before SQLite reports the index busy. store.commit then warns and waits again.

read_timeout: float = 10.0[source]#

Seconds a reader of a run waits for the index while the recorder holds it.

page_rows: int = 100000[source]#

Number of rows, or of row ids, one statement reads. The recorder writing the run cannot commit while a statement runs.

crashed_after: int = 3[source]#

Heartbeat periods without a heartbeat after which a run marked as running reads as crashed.

abandoned_after: float = 600.0[source]#

Seconds without a heartbeat after which a run marked as running is taken as abandoned by its process. Used when that process cannot be looked up.

creation_expires_after: float = 3600.0[source]#

Seconds after which the directory of a run left half created, by a process that ended while creating it, is removed by the next run created beside it.

git_untracked: int = 200[source]#

Maximum number of untracked files listed in run.json.
